## Overview

Select public packages from workspace configuration or an explicit directory list without installing dependencies.

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-nodejs/actions/package/discover@<sha>
  with:
    # Project root containing package.json and package manager configuration.
    # Default: `.`
    working-directory: .

    # Optional JSON array of public package directories relative to working-directory. Empty discovers workspaces, or the standalone root package.
    directories: ""
```
