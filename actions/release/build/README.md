## Overview

Build the checked-out release source and preserve artifact paths for packaging, independently of CI checks.
See the [release guide](../../../docs/usage/releases.md) for configuration and the CI boundary.

<!-- overview:end -->

## Inputs

| **Input**               | **Description**                                                                                                                                                         | **Required** | **Default**                                  |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------- |
| **`working-directory`** | Project directory relative to the caller repository root. Check out the release source before calling this action.                                                      | **false**    | `.`                                          |
| **`build`**             | JSON object with commands (script names), artifact (paths or an object with paths), and optional env. Artifact paths are relative to the project directory or absolute. | **false**    | `{"commands":["build"],"artifact":["dist"]}` |
