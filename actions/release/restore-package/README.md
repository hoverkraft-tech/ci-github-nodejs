## Overview

Validate a CI tarball, check an exact npm version and restore its original tarball with integrity verification when resuming publication.

<!-- overview:end -->
<!-- inputs:start -->

## Inputs

| **Input**          | **Description**                                                              | **Required** | **Default** |
| ------------------ | ---------------------------------------------------------------------------- | ------------ | ----------- |
| **`name`**         | Expected npm package name.                                                   | **true**     | -           |
| **`version`**      | Expected committed package version.                                          | **true**     | -           |
| **`tarball-path`** | Local tarball path to replace with the original published bytes on recovery. | **true**     | -           |
