## Overview

Apply the HoverKraft Conventional Commit plan to one public npm package and dispatch publication from the committed tag.

<!-- overview:end -->
<!-- inputs:start -->

## Inputs

| **Input**               | **Description**                                                                                                                          | **Required** | **Default**           |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------ | --------------------- |
| **`working-directory`** | Public npm project directory containing its package.json and lockfile.                                                                   | **false**    | `.`                   |
| **`github-token`**      | Token with contents and actions write and pull-requests read permissions. Its identity must be allowed to push release commits and tags. | **false**    | `${{ github.token }}` |

## Outputs

| **Output**     | **Description**                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| **`status`**   | One of no-changes, dispatched, ready or released. Only ready should start building, followed by publication. |
| **`packages`** | JSON array containing the public npm package at the committed release version.                               |
