## Overview

Create scoped release notes and an optional AI summary with HoverKraft, preserving independent package tag history.

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-nodejs/actions/release/draft@<sha>
  with:
    # Optional partial release configuration as a YAML or JSON mapping, forwarded to ci-github-publish/actions/release/create.
    # See https://github.com/hoverkraft-tech/ci-github-publish/tree/main/actions/release/create for supported settings and override behavior.
    # Use the same configuration as release preparation.
    release-config: ""

    # Prepared release tag.
    # This input is required.
    tag: ""

    # Release notes scope relative to the repository root.
    # Default: `.`
    working-directory: .

    # Package name for an independent Lerna release. Empty for repository-wide releases.
    package-name: ""

    # Optional complete JSON summary configuration forwarded unchanged to ci-github-publish/actions/release/create.
    # Supports all upstream provider, model, credential, model configuration, working directory and template options.
    # An empty value disables summarization. See https://github.com/hoverkraft-tech/ci-github-publish/tree/main/actions/release/create.
    changelog-summary: ""
```
